# Exercício 01 — Git Flow Básico

## Dificuldade: Médio 🟡

---

## 📋 Descrição

Simular o fluxo Git Flow com branches main, develop e feature.

---

## 🎯 Objetivo

Praticar a estrutura de branches do Git Flow.

---

## 📝 Passo a passo

### Passo 1: Criar estrutura base
```bash
mkdir git-flow-teste
cd git-flow-teste
git init

echo "# Projeto" > README.md
git add . && git commit -m "Commit inicial"
```

### Passo 2: Criar branch develop
```bash
git checkout -b develop
```

### Passo 3: Criar feature
```bash
git checkout -b feature/login develop
echo "Login functionality" > login.txt
git add . && git commit -m "Implementar login"
```

### Passo 4: Merge feature no develop
```bash
git checkout develop
git merge --no-ff feature/login -m "Merge: feature login"
git branch -d feature/login
```

### Passo 5: Criar release
```bash
git checkout -b release/1.0 develop
echo "1.0.0" > version.txt
git add . && git commit -m "Versão 1.0.0"
```

### Passo 6: Merge release na main
```bash
git checkout main
git merge --no-ff release/1.0 -m "Release 1.0.0"
git tag -a v1.0 -m "Versão 1.0.0"
```

### Passo 7: Merge release no develop
```bash
git checkout develop
git merge --no-ff release/1.0
git branch -d release/1.0
```

### Passo 8: Documentar
Crie `git_flow.txt`:
```
Branches criadas: main, develop, feature/login, release/1.0
Merge strategy: --no-ff
Tag criada: v1.0
Branches deletadas: feature/login, release/1.0
```

---

## 🔍 Verificação

1. A branch develop existe? ✅
2. A feature foi mergeada com --no-ff? ✅
3. A release foi taggeada? ✅
4. As branches temporárias foram limpas? ✅
