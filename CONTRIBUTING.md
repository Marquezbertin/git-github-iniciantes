# Guia de Contribuição

Obrigado por querer contribuir com este projeto! Aqui estão as formas de ajudar:

## Tipos de Contribuição

### 🐛 Reportar Bugs
- Abra uma **Issue** descrevendo o problema
- Inclua o módulo e exercício afetados
- Descreva o que você esperava vs. o que aconteceu

### 📝 Melhorar Conteúdo
- Correções de português ou digitação
- Sugestões de exercícios novos
- Melhorias nas explicações

### ✨ Adicionar Conteúdo
- Novos exercícios para módulos existentes
- Dicas práticas ou atalhos úteis
- Exemplos reais do dia a dia

## Como Contribuir

1. Faça um **fork** deste repositório
2. Crie uma **branch** para sua mudança
3. Faça suas alterações
4. Abra um **Pull Request** com descrição clara

## Regras

- Mantenha o conteúdo em **português**
- Siga o formato dos exercícios existentes
- Teste os comandos antes de enviar
- Uma mudança por Pull Request
