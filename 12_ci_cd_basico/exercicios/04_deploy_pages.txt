# Exercício 04 — Deploy Pages

## Dificuldade: Difícil 🔴

---

## 📋 Descrição

Criar workflow que faz deploy automático para GitHub Pages.

---

## 🎯 Objetivo

Automatizar a publicação do site a cada push na main.

---

## 📝 Passo a passo

### Passo 1: Criar workflow
```yaml
# .github/workflows/deploy.yml
name: Deploy GitHub Pages

on:
  push:
    branches: [main]

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v4
      - uses: actions/upload-pages-artifact@v3
        with:
          path: '.'
      - id: deployment
        uses: actions/deploy-pages@v4
```

### Passo 2: Criar index.html
```html
<!DOCTYPE html>
<html lang="pt-BR">
<head><title>Deploy Automático</title></head>
<body>
    <h1>Site publicado automaticamente!</h1>
    <p>Último deploy: via GitHub Actions</p>
</body>
</html>
```

### Passo 3: Configurar Pages
Settings → Pages → Source: "GitHub Actions"

### Passo 4: Push e verificar
```bash
git add .
git commit -m "Deploy automático para Pages"
git push
```

### Passo 5: Documentar
Crie `deploy_config.txt`:
```
Workflow: deploy.yml
Trigger: push na main
Permissões: contents, pages, id-token
Actions usadas: 4
Deploy: sim/não
URL: [url do site]
```

---
