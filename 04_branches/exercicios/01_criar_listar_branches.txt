# Exercício 01 — Criar e Listar Branches

## Dificuldade: Fácil 🟢

---

## 📋 Descrição

Aprender a criar, listar e gerenciar branches no Git.

---

## 🎯 Objetivo

Conhecer os comandos básicos de branch: criar, listar e renomear.

---

## 📝 Passo a passo

### Passo 1: Criar repositório com commits
```bash
mkdir branches-teste
cd branches-teste
git init

echo "Principal" > main.txt
git add . && git commit -m "Arquivo principal"
```

### Passo 2: Criar branches
```bash
git branch feature-login
git branch feature-cadastro
git branch bugfix-cor
```

### Passo 3: Listar branches
```bash
git branch
git branch -v
```

### Passo 4: Renomear uma branch
```bash
git branch -m bugfix-cor hotfix-cor
git branch
```

### Passo 5: Documentar
Crie `branches_criadas.txt`:
```
Branches criadas: [lista]
Branch renomeada: bugfix-cor → hotfix-cor
Branch atual (com *): main
Total de branches: [número]
```

---

## ✅ Saída esperada

```
$ git branch
  bugfix-cor
  feature-cadastro
  feature-login
* main

$ git branch -v
  bugfix-cor
  feature-cadastro
  feature-login
* main    a1b2c3d Arquivo principal
```

---

## 🔍 Verificação

1. 3 branches foram criadas? ✅
2. `git branch` lista todas? ✅
3. A branch renomeada mudou de nome? ✅
4. Criou o arquivo de documentação? ✅
