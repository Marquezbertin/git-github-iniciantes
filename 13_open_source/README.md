# Módulo 13 — Open Source

## 📖 O que você vai aprender

Como contribuir para projetos open source, boas práticas e documentação para contribuidores.

---

## 🌍 O que é Open Source?

Código-fonte disponível publicamente para qualquer pessoa ver, usar, modificar e distribuir.

### Benefícios:
- Aprender com código real
- Construir portfólio
- Conectar-se com a comunidade
- Dar retorno à comunidade

---

## 📝 Contribuindo

### Passo a passo:
1. Encontre um projeto
2. Leia CONTRIBUTING.md
3. Abra uma Issue antes de começar
4. Faça fork e clone
5. Crie branch
6. Implemente
7. Abra PR
8. Responda ao review

### Regras de ouro:
- Leia as regras ANTES de contribuir
- Comece com Issues pequenas
- Siga o estilo do projeto
- Seja paciente e educado
- Uma mudança por PR
