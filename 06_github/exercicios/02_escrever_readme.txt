# Exercício 02 — Escrever README

## Dificuldade: Fácil 🟢

---

## 📋 Descrição

Escrever um README.md completo e enviá-lo para o GitHub.

---

## 🎯 Objetivo

Criar um README.md profissional que descreva seu projeto claramente.

---

## 📝 Passo a passo

### Passo 1: Editar o README.md
Substitua o conteúdo por:
```markdown
# Meu Primeiro GitHub

## Sobre
Este é meu primeiro repositório no GitHub, criado durante o curso de Git e GitHub.

## O que aprendi
- Criar repositórios
- Clonar repositórios
- Escrever READMEs em Markdown

## Próximos passos
- Aprender mais sobre Git
- Contribuir para projetos open source
```

### Passo 2: Visualizar o Markdown
Copie o conteúdo e cole em https://markdownlivepreview.com/

### Passo 3: Commit e push
```bash
git add README.md
git commit -m "Atualizar README com conteúdo do curso"
git push
```

### Passo 4: Verificar no GitHub
Acesse o repositório e veja o README renderizado.

### Passo 5: Documentar
Crie `readme_escrito.txt`:
```
README criado: sim/não
Secções incluídas: [lista]
Markdown funcionou: sim/não
Enviado ao GitHub: sim/não
```

---

## 🔍 Verificação

1. O README tem título, seções e listas? ✅
2. O Markdown renderiza corretamente no GitHub? ✅
3. O commit e push foram realizados? ✅
