# Exercício 04 — README Avançado

## Dificuldade: Médio 🟡

---

## 📋 Descrição

Criar um README.md com badges, imagens, tabelas e formatação avançada.

---

## 🎯 Objetivo

Dominar Markdown avançado para criar READMEs profissionais.

---

## 📝 Passo a passo

### Passo 1: Criar README com elementos avançados
```markdown
# ![Git](https://img.shields.io/badge/Git-F05032?style=flat&logo=git&logoColor=white) Projeto Avançado

> Um projeto que demonstra README avançado no GitHub

---

## Funcionalidades

- [x] Configuração automática
- [x] Testes unitários
- [ ] CI/CD
- [ ] Deploy

## Tecnologias

| Tecnologia | Uso |
|-----------|-----|
| Git | Controle de versão |
| GitHub | Hospedagem |
| Markdown | Documentação |

## Como usar

### Pré-requisitos
- Git instalado
- Conta no GitHub

### Instalação
```bash
git clone https://github.com/USUARIO/projeto.git
cd projeto
```

## Contribuindo

1. Fork o projeto
2. Crie uma branch
3. Faça seu commit
4. Abra um Pull Request

## Licença

MIT License - veja [LICENSE](LICENSE) para detalhes
```

### Passo 2: Push para o GitHub
```bash
git add README.md
git commit -m "README avançado com badges e tabelas"
git push
```

### Passo 3: Documentar
Crie `readme_avancado.txt`:
```
Elementos incluídos:
- Badges: sim/não
- Tabela: sim/não
- Checkbox: sim/não
- Código com linguagem: sim/não
- Links internos: sim/não
- Separador: sim/não
```

---

## 🔍 Verificação

1. O README renderiza badges? ✅
2. A tabela aparece formatada? ✅
3. Os checkboxes funcionam? ✅
4. O código tem syntax highlighting? ✅
