# Módulo 15 — Projeto Prático

## 📖 O que você vai aprender

Criar um projeto completo do zero, aplicando todos os conhecimentos dos 14 módulos anteriores.

---

## 🎯 Objetivo Final

Criar um repositório open source profissional que demonstre tudo o que você aprendeu:

- Repositório bem documentado
- Commits organizados e descritivos
- Branches para desenvolvimento
- CI/CD configurado
- Contribuições da comunidade
- Publicado no GitHub

---

## 📋 Checklist do Projeto

- [ ] README.md profissional com badges
- [ ] Estrutura de pastas organizada
- [ ] CONTRIBUTING.md
- [ ] CODE_OF_CONDUCT.md
- [ ] LICENSE
- [ ] Issue templates
- [ ] PR template
- [ ] GitHub Actions (CI)
- [ ] Pelo menos 3 commits descritivos
- [ ] Branch develop (Git Flow)
- [ ] Tags para versões
- [ ] Contribuições reais (mesmo que suas próprias)

---

## 🏗️ Estrutura do Projeto

```
meu-projeto/
├── README.md
├── CONTRIBUTING.md
├── CODE_OF_CONDUCT.md
├── LICENSE
├── .github/
│   ├── ISSUE_TEMPLATE/
│   │   ├── bug_report.md
│   │   └── feature_request.md
│   ├── PULL_REQUEST_TEMPLATE.md
│   ├── CODEOWNERS
│   └── workflows/
│       └── ci.yml
├── src/
│   └── main.py (ou outro)
├── docs/
│   └── guia.md
└── exercicios/
    └── 01_exercicio.txt
```
