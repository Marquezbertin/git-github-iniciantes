## Sobre

Este repositório é um curso estruturado de Git e GitHub, ideal para quem está começando na programação ou quer dominar controle de versão. Cada módulo contém:

- **Teoria explicada** com exemplos reais
- **Comandos práticos** para executar no terminal
- **6 exercícios** com dificuldade progressiva (Fácil → Médio → Difícil)
- **Verificação** para confirmar que o exercício foi concluído

---

## Como Usar

1. **Clone** este repositório:
```bash
git clone https://github.com/seu-usuario/git-github-iniciantes.git
cd git-github-iniciantes
```

2. **Siga a ordem** dos módulos (01 a 15) — cada um builda sobre o anterior.

3. **Pratique** os exercícios de cada módulo antes de avançar.

4. **Crie seu próprio repositório** para registrar sua jornada de aprendizado.

5. **Contribua!** Encontrou um erro? Abra uma Issue ou envie um Pull Request.
